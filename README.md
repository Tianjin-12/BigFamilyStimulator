# 家族模拟器 M1

从一对创始夫妻出发，在有限村庄中模拟数百年人口演替，观察父系血脉能否永续。
设计文档见 `DESIGN.md`；玩法扩展设计方案（可玩性/传播性/深度四方向）见 `DESIGN_PROPOSALS.md`。

## 运行

```bash
# 单次模拟（CLI 报表 + ASCII 人口曲线）
python cli.py --seed 42

# 自定义血脉始祖姓名（姓 1-2 字支持复姓，名 1-2 字；后代沿父姓传承）
python cli.py --seed 9 --founder-surname 欧阳 --founder-given 明月

# 导出 JSON（谱系图数据，供 viewer 用）
python cli.py --seed 30 --json-out viewer/run30.json

# 批跑 + 聚合（断绝率/原因分布/存续年数/世代/人口分位带）
python -m runner.batch --n 200 --out results/m2_full

# 参数扫描（如：终身生育上限 5/6/7/8 对断绝率的影响）
python -m runner.batch --n 100 --sweep "parity_cap_base:5,6,7,8" --out results/sweep_cap

# 测试（复现性/亲等边界/频率校验/行为开关/风物层隔离，17 项）
PYTHONPATH=. python tests/test_core.py
```

## 起名（后端，真实遗传链）

起名在 sim-core 完成（`sim_core/namer.py`），Person 自带 `name` 字段：
- 姓：**继承父亲**——谱系真实传播；创始者/移民从姓氏库按权重抽
- 名：出生时期带（10 年）× 性别对应池抽取；风尚随时代演进
  （古朴→汉风→魏晋→隋唐→诗雅→朴直→宗法）
- 名字库为**人类可编辑的多文件**（每池约 20 名，可手动丰富）：
  ```
  sim_core/names/surnames.txt          # 姓氏库：每行"姓 权重"
  sim_core/names/male/band_000.txt     # 第 0 带（y0-9）男名池
  sim_core/names/female/band_042.txt   # 第 42 带（y420-429）女名池
  ```
  文件内 `#` 开头为注释；带越界自动回退最后一池
- RNG 走独立 `name` 子流——改名字库不破坏其他随机事件的复现性
- 前端 `viewer/names.js` 只做薄适配（nameOf/姓氏排行），名字来自后端

## 实时模式（live）

```bash
python server.py            # 然后浏览器打开 http://localhost:8642/viewer/live.html
```

- **封面主菜单**：打开即见——开始游戏（有进行中的世界则瞬时续上，否则弹新世界向导）、
  新的一局、存档馆（含总览统计）、成就殿堂、世界之规；同心圆世代纹背景 + 楷体金字
- **存档系统**：存档 = 「种子 + 参数 + 始祖 + 年份」的极小 JSON，读档时确定性重放逐字节还原；
  自动存档按世界分槽（保留最近 3 份，间隔可在设置里调，断绝/终局必补一档）；
  手动存档可命名；单档导出 JSON 分享、他人 JSON 一键导入、全量备份导出/导入；
  总览统计对全部本地存档做描述性统计（存续年数/世代/人口的均值·中位数·极值·标准差、
  存续年数分布直方图、断绝原因分布）
- **成就系统**：10 枚初始成就，条件覆盖单局全程（创世/添丁/男丁/人口/世代/高寿/百年/三百年/千年）；
  解锁永久保存（localStorage，跨世界跨存档），解锁时右上角金光横幅；
  卡片带实时进度条；一键生成 1280×800 金框分享海报（先预览再下载 PNG）
- **设置**：默认播放速度、谱系出生闪光开关、成就弹窗开关、自动存档间隔、
  数据管理（导入备份/清空成就/删除所有存档）；全部持久化到本地
- **边算边看**：播放/暂停/变速（慢-极速）/+1 年/+10 年（连点自动排队不丢步），快捷键 Space、→、Shift+→
- **世界感**：世界纪年+纪元名（洪荒/耕稼/鼎盛…，新纪附一句风物志）、时期徽章（当前生育 p/夭折率/K）、
  时间轴（时期带着色+人口/血脉迷你曲线+断绝标记，点击可前跳）
- **创始者姓名**：新世界对话框可自定义血脉始祖的姓与名（汉字格式校验；复姓可），
  后代按父姓真实传承
- **风物叙事层**（`flavor_events` 参数，默认开；只消耗独立 RNG 子流，不影响模拟结果与复现性）：
  天时丰歉（随时艰度分档）、村中最年长者辞世、血脉男丁冠礼、人口里程碑、集市/孩童/狼患等杂闻、
  婚宴播报（"本年成婚 N 对——某某 ⚭ 某某 最先拜堂"）、血脉讣告（一生 N 子）、移民附原籍；
  民生流水每 5 年汇总一条，血脉主线事件金边高亮不喧宾夺主
- **村志**：右侧栏"村志"标签页实时滚动大事记（纪元/血脉添丁及代次/里程碑/冠礼/送老/丰歉/断绝），
  页首"村庄之最"聚合榜（史上最寿/儿女最多/第一大姓/血脉世传），一键导出 txt；
  人物面板带数据驱动称号与一行小传，亲属跳转自动居中并点亮直系光圈
- 谱系树实时生长（血脉男丁出生闪光）+ 视图工具条（缩放/全览/聚焦血脉/定位选中者）、
  年龄-性别金字塔、事件流（自动滚到最新；迁移事件带人名、年度生死纪事、血脉危急预警）、
  点击人物侧栏（亲属链接跳转自动居中）
- **✦ 新世界**：改 seed、村庄规模、生育上限、禁婚亲等 k、生育/死亡压力外，
  还有两个行为开关——渐进撮合（每年最多 N 对，替代首年全配完）、
  血脉外迁保护（降低血脉男丁被外迁抽中的概率）；开关默认关闭，默认参数下与旧 seed 逐字节复现一致
- **血脉断绝**：弹操作卡（继续观察村庄 / 一键 seed+1 再开新世界）；断绝原因中文化（E1-E6）

## viewer

浏览器直接打开 `viewer/index.html`（或本地起 http 服务后访问 `?src=viewer/run30.json`），
拖入 cli.py 导出的 run JSON：
- 谱系树：滚轮缩放、拖动平移、点击人物侧栏（生卒/属性/父母配偶子女跳转）
- 人口曲线（村庄总人口 + 血脉男丁 + 断绝标记）、血脉世代直方图、时期参数曲线

## 结构

```
sim_core/     纯核心（无 IO，种子注入，逐字节可复现）
  params.py   参数表 + 死亡率锚点曲线（古代/现代两档插值）
  rng.py      RNG 分流（era/match/birth/death/migrate 五子流）
  person.py   Person 数据模型（genes 字段为 M3 预留）
  kinship.py  亲等判定（直系无限代 + 旁系分叉深度 k，缓存加速）
  village.py  村庄状态 + 年事件流水线（出生→撮合→死亡→迁移→断绝检查）
  engine.py   引擎入口（创始村播种 + 主循环）
runner/       批量运行 + 聚合统计 + 参数扫描（batch.py）
viewer/       网页谱系可视化
  live.html   实时模式页面（封面 + 游戏 + 元系统对话框）
  live.js     实时游戏逻辑（快照合并/绘制/交互）
  meta.js     元系统：设置 / 成就 / 存档馆 / 总览统计 / 分享图
  index.html + app.js   离线谱系查看器（无依赖无服务器）
server.py     live HTTP 服务（/api/new、/api/step、快照带 world_meta 创建凭据）
tests/        M1 验收测试
```

### 存档 JSON 格式（可分享）

```json
{
  "format": "family-sim-save", "version": 1,
  "name": "欧阳氏血脉 seed7", "savedAt": "2026-08-27T…",
  "world": { "seed": 7, "overrides": {}, "founder": {"surname": "欧阳", "given": "明月"} },
  "year": 137,
  "stats": {"pop": 210, "lineage_male": 3, "max_lineage_gen": 5, "…": "…"},
  "outcome": {"extinct_year": null, "reasons": []}
}
```

读档 = `POST /api/new`（同种子同参数同始祖）后快进到 `year`，逐字节还原；
成就数据**不**随存档走（防止移植他人存档刷成就）。

## M1 已知状态

- 默认参数下断绝率 ~90%+，多在百年内（E1 无男丁出生为主）——
  父系血脉 + 每代 1-3 个男丁的真实瓶颈数学（姓氏消亡研究结论一致）。
  参数空间探索（生育上限/死亡率/禁婚亲等 k 对断绝率的影响）留给 M2 runner。
- 断绝原因分类 E1-E5、四种终止态、时期参数 AR(1) 抽样、村庄承载 K 均已实现。
- 撮合为一夫一妻、丧偶不再婚（`remarriage` flag 预留）。
